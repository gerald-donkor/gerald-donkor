## About

I'm a design engineer who bridges design and code — building interfaces that feel intuitive, move with intention, and hold up under real engineering rigor. My focus is the layer where visual design, interaction, and front-end architecture meet.

---

## What I Do

* 🎨 Design and build polished, responsive interfaces with React, Next.js, and TypeScript
* ✨ Craft motion and micro-interactions with GSAP and Motion
* 🧩 Build reusable, accessible component systems and design-token-driven UI
* 🖌️ Translate Figma designs into pixel-accurate, production-grade code
* ⚡ Optimize for performance, accessibility, and interaction quality
* ⚙️ Ship full-stack features end-to-end when the product needs it
