## About

I design and engineer polished, interactive web experiences, combining thoughtful interface design with strong frontend engineering to build products that feel intuitive, fast, and refined.

---

## What I Do

* 🎨 Design and build polished, responsive interfaces with React, Next.js, and TypeScript
* ✨ Create engaging motion and interactive experiences with GSAP and Motion
* 🧩 Develop reusable components and scalable frontend architecture
* ⚡ Prototype ideas and refine them for performance, accessibility, and usability
