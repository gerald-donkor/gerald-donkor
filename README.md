## About

I craft exceptional digital experiences and engineer scalable applications, combining intuitive interfaces, thoughtful interactions, and robust architecture to build refined, high-performance digital products.

## What I Do

* 🎨 Design and build polished, responsive interfaces with React, Next.js, and TypeScript
* ⚙️ Engineer full-stack applications, APIs, and scalable backend systems
* ✨ Create engaging motion and interactive experiences with GSAP and Motion
* 🧩 Develop reusable components and maintainable application architecture
* 🗄️ Design and integrate databases, authentication, and backend services
* ⚡ Optimize applications for performance, accessibility, and usability
