## About
I create modern, responsive, user-centered web products by combining thoughtful design with clean, scalable engineering.
What drives me is crafting digital experiences that feel intuitive — the kind people genuinely enjoy using.

## What I Do
I combine product thinking, design, and engineering to build user-centric, front-facing products that are seamless, performant, and production-ready.

* 🎨 Responsive, accessible interfaces
* 🧩 Design systems & reusable components
* ✨ Motion & 3D — GSAP, WebGL, Three.js
* ⚡ Performance-focused, core web vitals in mind
* 🤖 Fluent with AI coding tools
* ⚙️ Full-stack apps & APIs, built with strong TypeScript
